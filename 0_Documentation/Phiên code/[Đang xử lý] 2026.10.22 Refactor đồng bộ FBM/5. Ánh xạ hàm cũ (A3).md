# Ánh xạ hàm đồng bộ FBM sang đích (A3)

Bảng ánh xạ hàm cũ của đợt refactor, lập ở bước A3. Mỗi tệp code trong phạm vi refactor liệt kê các hàm không giữ nguyên và đích của nó (xóa, gộp, tách, chuyển, thành nhánh của một người điều phối, hoặc giữ kèm một sửa nhỏ); hàm không có tên ở đây thì giữ nguyên. Nội dung lấy từ bảng A2 (7 agent đọc trọn), mã K1–K10 trỏ về mục 11 của `2. Thiết kế đích.md`. Chỗ nào `2. Thiết kế đích.md` quyết khác thì tài liệu đó thắng. Bước B làm xong hàm nào thì xóa dòng đó; C4 xóa cả tệp.
